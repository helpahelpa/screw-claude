Vendored from https://github.com/tabler/tabler-icons/tree/a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d/icons/outline

Only selected original icon paths are bundled; no third-party browser requests. The Focus polish extends the sprite with 11 icons from the same pinned version for the eight checks and supporting section headings. Existing symbols are retained.

Geist and Geist Mono are self-hosted variable WOFF2 fonts, subset to the Latin UI characters. Noto Sans SC is a self-hosted WOFF2 subset of the Chinese UI characters. Subsets were downloaded through the Google Fonts CSS API at build time. SIL Open Font Licenses are included beside the fonts. Original prototype fonts remain unchanged.
